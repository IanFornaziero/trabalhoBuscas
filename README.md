# Trabalho de buscas - Matéria de Inteligência Artificial

## Resumo do trabalho
Basicamente uma aplicação que utiliza 4 algoritmos de busca **(busca em largura, busca em profundidade, busca gulosa e A**
Ao executar um algoritmo, ele salva todas as informações em um txt.

**ATENÇÃO**
O arquivo txt é gerado no seguinte caminho: **user/%appdata%/Godot/app_userdata/trabalho-buscas/caminho.txt**
E a cada inicialização ele reseta o arquivo

Para testar basta executar o .exe na pasta executaveis no projeto, ou abrir o projeto na própria engine.
